Detailed Description

List of keys.

This union represents the state of the buttons on a controller. Read a button through its bit field (e.g. osl_keys->held.cross) or test value against an OSL_KEY_MASKS value:

Field Bit Button
select 0 Select
start 3 Start
up, right, down, left 4, 5, 6, 7 D-pad
L, R 8, 9 Shoulder buttons
triangle, circle, cross, square 12, 13, 14, 15 Face buttons
home 16 Home (may not work)
hold 17 Hold (power switch in the opposite direction)
note 23 Note (may not work)

The other bits are reserved.
